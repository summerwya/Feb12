# Feb 12 - 02 Performance Task 1

Using Android Studio, create an app that has **two (2) text fields** and **one (1) button**. The button will **compare the input from the text fields and display a response** (**SAME** if values are the same and **NOT THE SAME** if they are not) if it is clicked.

## Activity Criteria

- **Speed** – amount of time accomplishing the activity and punctuality of submission
- **Error-Free** – whether app runs smoothly or with major errors (errors that break the app’s operation)
